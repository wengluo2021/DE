**M1必须沿用的入口。**

- `Claim.text` 不允许内嵌 `[数字]` 引用；编号只能来自citation_numbers，再由 `render_answer(claims)` 生成展示文本。
- `hit.validate_source(document)`：校验冻结正文区间、标题、URL、实际覆盖条文和条号；必须在交给模型前显式调用。
- `result.validate_snapshot(retrieval)`：核对Answer与原SearchResult版本一致，全部本轮命中原样保存，包括未被claims引用的证据；必须显式调用。
- `ModelOutput` 只接受status/claims，不接受另一份自由文本answer；insufficient只能空claims，最终拒答用INSUFFICIENT_ANSWER。
- `load_settings(...)` 不import B重型模块、不联网、不搜索其他课程密钥、不修改os.environ。
- 配置优先级为显式overrides/api_key → 进程environ → 显式/default .env → JSON；`api_key=''`可清空，空白Key按未配置。
- `Settings.retrieval_config()` 返回供现有B使用的新字典。`public_snapshot()`不含Key；`experiment_fingerprint()`不含机器路径与凭据状态，包含prompt内容hash。
- 正式模式要求语料/题集SHA-256形状；实际manifest与版本真实性仍由后续A/B加载和校验验证，不能把语法通过当正式数据存在。
