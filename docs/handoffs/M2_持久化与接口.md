**对外接口与状态。**

- POST `/api/ask`：输入AskRequest，成功返回原AskResult；保存本轮全部证据，失败也保留问答记录。
- GET `/api/conversations`：items列表；GET `/api/conversations/{id}`：问题、有效结果/错误和证据快照。原始provider候选/内部trace不在普通历史接口回显，数据库内部仍保留用于评估。
- GET `/api/tasks/{id}`：queued/running/completed/failed、进度、结果/错误及result_id。
- GET `/api/health`：服务存活与组件就绪分开，公开脱敏配置和实验指纹；不会为检查健康而调用模型。模型已配置不表示已验证连通。
- 原B的文档/建库/检索/对照路由已注册到正式入口；没有正式资料时返回明确409，不自动启用fixture或演示回答。
- 错误统一code/message；422输入、404不存在、409版本/未配置、502/503生成/上游失败；无未验证答案当成功展示。

**关机与恢复语义。**

每次问答先保存running和请求/实际配置，在检索验证后以及每次生成尝试保存进度，结果与证据在事务中完成。硬中断后由下一次持有数据库租约的服务把遗留running问答、queued/running任务标记PROCESS_INTERRUPTED，保留已有快照、响应和进度；不偷偷重新请求模型。

任务的Python函数不序列化或pickle；重启后旧任务标失败，需要新建任务重跑。正常关闭会等自己的工作器完成再释放租约。生产仅使用一个服务进程/worker，不开启自动重载；评估CLI在M3只作为HTTP客户端。

`QAService.ask_with_trace`新增仅内部使用的ask_id/on_progress参数；原公开ask签名保持兼容。trace新增sources_verified、实际配置与指纹，失败也可复核当时模型/prompt。SQLite把未通过来源核验的失败证据标未验证，不作为正常引用回答。
