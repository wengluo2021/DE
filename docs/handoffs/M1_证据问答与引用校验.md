**Rules that must continue to be followed.**

1. `QAService` receives only the question, version, condition, document/retriever, and generator; it does not receive reference answers, gold evidence, or answerable labels. Each round is independent, and the previous round's answer is not sent to the model.
2. Retrieval results obtain hits, index_version, and elapsed time in one call. Official assembly may directly inject B's search_result, and must not retrieve again just to obtain metadata.
3. `validate_source` verifies the frozen slice against the authoritative title, URL, and provisions; `validate_snapshot` verifies that all evidence from this round is preserved as-is. Numbering starts from 1 each round, distinguished by ask_id.
4. The original text is not trimmed and line breaks are not changed; the prompt is hashed and decoded from the original bytes, and that version is fixed after initialization.
5. Zero hits directly produce a fixed refusal without calling the generator; when there are hits but they are insufficient, all evidence is still saved. Model/retrieval failures return QAError and are not disguised as insufficient.
6. Network retries and format/citation repair share at most 2 model calls. Authentication, TLS certificate, non-final output, etc. are not blindly retried; the model, prompt version, or retrieval results are not changed until the answer is correct.
7. Duplicate JSON keys, free-form answer, no citations, inline numbering in the body, out-of-range numbering, truncated/empty output are all rejected. Structural pass still requires subsequent human verification of factual support.
8. AskTrace provides retrieval, context_chars, each response/usage/error, timestamps, and error status; M2 should persist to disk, not only keep in-process.
