# M6评分方式：逐项人工确认与授权AI辅助分开记录

2026-11-20。在前5题逐项解释和确认后，用户明确要求：“之后的题目都这样无特别的不需要确认”。此前也明确要求持续完成任务，不在阶段结束时停止。

因此后续常规判断按已经解释的统一口径，由Codex AI完成并记录为**C授权的AI辅助评分**；只有会改变结论或口径的特殊争议单独询问。授权文件为`artifacts/c/m6-human-review/standing-authorization.json`，它是方法授权，不是用户已经逐题阅读全部答案的证明。

## 来源如何区分

- 用户逐项明确确认的记录，评审人保留`C（本聊天用户）`，对应真实回复与显式请求，不改写已有决定。
- 常规委托记录，评审人写`Codex AI（C授权辅助评分）`，备注明确未经逐题人工确认，并保留原AI建议、实际引用及理由。
- 特殊项若由实际人作决定，保存独立的实际回复和评分回执，再处理其他常规项。不会用AI身份冒充人类姓名。

整答按A冻结必要事实判correct/partial/wrong；引用按每条主张实际绑定的块判断；允许题目明确给定事实作上下文，不借未引用的法律规则补证。切片有效不等于语义支持，整体正确也不等于每条引用合格。已接受的例子与新的具体理由均保留。

## 结果怎样表述

数据库评分字段、已完成数量与逐题人工核验是不同概念。后端`review_complete`和`formal_results`表示其评分字段及正式运行条件满足，不能单独证明所有字段都由人类逐项复核。

报告和交付会列明逐项人工确认与授权AI的数量、范围和局限，称为混合来源的AI辅助实验评分，不称全部纯人工评分，也不把AI结果当作独立人工金标准。团队原规范中的人工评分要求与本次实际采用的方法一并披露，供组长审阅。

这次授权不改变冻结法规、题集、原模型输出或检索指标；不启动新120项实验，不重复收费测试。分阶段、自检、交接、本地分支保存、密钥隔离以及不push/不写main/不发团队消息的规则继续执行。
